# AC-8 机炮双倍弹仓弹夹 · AC-8 Double Capacity

**v1.0.0**

把 AC-8 机炮的弹仓与背包弹夹翻倍。

Doubles the AC-8 autocannon's magazine and backpack clips.

---

## 中文

### 功能

| 项目 | 原版 | 修改后 |
|---|---|---|
| 弹仓容量 | 10 发 | **20 发** |
| 背包弹夹 | 10 夹 | **20 夹**（共 100 发） |
| 每次补给 | 5 夹 | **10 夹** |
| 补弹阈值 | 6.0 | **16**（= 容量 − 4） |

装上即生效，无配置文件、无游戏内菜单。其它武器不受影响。

### 安装

1. 用 Arsenal 或 HD2MM 导入 `dist/` 下的 zip
2. 启用后 **Purge → Deploy**
3. 需要 **Bingus Shared Loader v15+ / API 1**

### 日志

```
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\AutocannonCapacity_STATUS.log
```

认这行 `revision=1.0.0` 即新版生效。

## English

### Features

| Item | Vanilla | Modified |
|---|---|---|
| Magazine capacity | 10 rounds | **20 rounds** |
| Backpack clips | 10 clips | **20 clips** (100 rounds) |
| Per resupply | 5 clips | **10 clips** |
| Top-up threshold | 6.0 | **16** (= capacity − 4) |

Takes effect once deployed — no config file, no in-game menu. Other weapons are unaffected.

### Install

1. Import the zip from `dist/` with Arsenal or HD2MM
2. Enable it, then **Purge → Deploy**
3. Requires **Bingus Shared Loader v15+ / API 1**

### Log

```
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\AutocannonCapacity_STATUS.log
```

Look for `revision=1.0.0` to confirm the new version is active.
